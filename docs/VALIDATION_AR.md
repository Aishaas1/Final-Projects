## النتائج المؤكدة

بيئة Linux وPython3.12.14 بلا GPU؛ ثُبّت PyTorch2.5.1+cpu وTorchvision0.20.1+cpu وGradio5.50.0 داخل `/workspace/.venvs/facejpeg`. تفاصيل الإصدارات في `artifacts/environment_versions.json`. نُفّذ نص التثبيت المحفوظ فعليًا، ثم أُعيد تشغيله بعد إضافة IPython ونجحت اختبارات المشروع.

- **6 اختبارات ناجحة، لا فشل ولا تخطٍ في التشغيل النهائي**: التكرارات بالبكسلات ونسخة JPEG القريبة وتجميع الهوية وتقسيمها؛ إنشاء JPEG مستقل من الأصل؛ مقامات المقاييس وحدود القرار؛ منع مسار ZIP متجاوز؛ الملف التالف والصورة بلا وجه وعدة الوجوه؛ إعادة تحميل checkpoint وتطابق درجة مسار الواجهة مع الدالة المباشرة. اختبار فرع تعدد الوجوه داخل الوحدة يستخدم mock، ويكمله اختبار API حقيقي أدناه. تقرير JUnit في `artifacts/pytest.xml`.
- **تدريب فعلي لاختبار البرمجيات**: 40 صورة هندسية غير بشرية من `scripts/make_demo.py`؛20 لكل رمز فئة. التقسيم28 تدريب و6 تحقق و6 اختبار. استُخدمت أوزان ImageNet الرسمية المتحققة بالتجزئة، وتدرّب رأس التصنيف على CPU لحقبتين. ملفات `artifacts/smoke/best.pt` و`last.pt` و`history.csv` و`run_info.json` ناتجة عن هذا التشغيل. الوسم `SMOKE_ONLY_NOT_A_FACE_DETECTOR` محفوظ داخل الأوزان والتحذير ظاهر في الواجهة والتقرير.
- **الحفظ والاستكمال**: شُغّلت حقبة ثم استُكمل التدريب إلى إجمالي حقبتين من last.pt. وقورنت النتيجة بتدريب مستقل متصل لحقبتين بالبذرة والبيانات والإصدارات نفسها؛ تطابق سجل الخسائر وجميع tensors النهائية تمامًا على CPU. الدليل `artifacts/resume_validation.json`. لم يُجرَّب انقطاع Google Drive فعلي داخل Colab؛ لا نَعِد بتطابق بتّي عبر GPU أو منصات مختلفة.
- **JPEG**: قُيّمت6 صور الاختبار الهندسي في الحالات الخمس، أي30 سجل تنبؤ. حفظ CSV ورسوم JPEG ومصفوفات2×3 وأمثلة تبدّل حكم وتقرير عربي محسوب فعلًا في `artifacts/smoke/evaluation/`. لا تستخدم هذه الأرقام في عرض علمي على أنها دقة كشف وجوه؛ الدوائر والمستطيلات ليست صورًا فوتوغرافية ووجوهًا مولّدة. أفضل تحقق كان BCE≈0.5138264 والحدان low=0.425 وhigh=0.575، وهذه أرقام الاختبار الهندسي فقط.
- **واجهة Gradio عبر API حقيقي**: شُغّلت محليًا بلا رابط عام. استُخدمت الصورة التوضيحية من README الرسمي لـFFHQ للاختبار فقط؛ وجد Haar10 وجوه في الصورة الكاملة، فرفضتها الواجهة برسالة عربية، ثم قُص وجه واضح واختُبر رفعه بنجاح. أعاد API صورتين224×224 ودرجتين وحكمين، وطابقت النصوص والدرجات الاستدعاء المباشر. لم تدخل صورة FFHQ التدريب أو ZIP. السجل `artifacts/ui_validation.json`.
- **جاهزية الخادم في البيئة المعزولة**: شُغّل أمر `python app.py --checkpoint artifacts/smoke/best.pt --port 7860` من البيئة المعزولة، ورد طلب HTTP بالحالة200، وأعاد رفع PNG أبيض عبر API رسالة «لم أجد وجهًا…». لم يُكتفَ بوجود منفذ مفتوح.
- **الدفتر**: نُفّذت المراحل1–8 من `FaceJPEG_Colab.ipynb` محليًا بالإعدادات الافتراضية، بما فيها التثبيت وتوليد العينة والتدقيق والتدريب وإعادة التحميل والتقييم. يحتوي الدفتر على مخرجات هذه الخلايا الحقيقية. جرى التحقق من بنية ipynb ومن تركيب جميع ملفات Python؛ كما نجح فحص ruff للأخطاء F. السجلان `artifacts/notebook_validation.json` و`notebook_validation.log`. الخلايا9–11 تفاعلية لم تُنفذ داخل خدمة Colab في هذه الجلسة؛ اختبار رفع الصورة وتشغيل الواجهة أُنجز عبر API المحلي كما وُصف.

## أين توقف التدريب على الوجوه؟

فُحصت أسماء المتغيرات وتهيئة البيئة دون طباعة قيم الأسرار؛ لا توجد متطلبات Kaggle أو متغيراته في الإعدادات. لم نفترض الحاجة إلى مفتاح بسبب عدم ظهوره. نُفّذ **برنامج التنزيل الفعلي** `python scripts/download_data.py --record data/download_attempt.json`، وفشل قبل الحصول على الإصدار أو تنزيل أي صورة عند طلب `api.kaggle.com/v1/datasets.DatasetApiService/GetDataset` بـ`ProxyError` و`Tunnel connection failed: 403 Forbidden`. يوجد الأثر في `artifacts/dataset_download_attempt.log`؛ تعود عبارته الأخيرة إلى صياغة رسالة قبل توحيد ترقيم الخلايا، أما الرسالة الحالية فتحيل إلى2 و4 بشكل صحيح. طلب صفحة www.kaggle.com فشل بالحجب نفسه. لم يثبت أن حسابًا أو سرًا مفقود، ولذلك لم نطلبهما.

فُتحت وثائق FFHQ وStyleGAN الأصلية عبر raw.githubusercontent.com وتحققت شروطهما المذكورة في بطاقة البيانات. **لم يمكن التحقق من ترخيص صفحة Kaggle الحالية أو حجم تنزيلها مباشرة**؛ حجم4GiB تقدير للتخطيط. يجب مراجعة الصفحة قبل الاستخدام العلمي أو إعادة التوزيع. لم تُنزّل مجموعة الوجوه، ولم تُجرَ عليها أي حقبة أو أي مقاييس، ولا تُرفق أوزان تدريب وجوه كامل. هذا عائق وصول بيانات، وليس فشلًا مثبتًا في النموذج على بيانات الوجوه.
