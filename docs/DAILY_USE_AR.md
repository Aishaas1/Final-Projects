# استخدام FaceJPEG في يوم آخر — الإصدار2.5

## لماذا اشتغل أمس ثم ظهر No module named facejpeg؟

Colab يشغّل الكود على جهاز مؤقت. عند انتهاء الجلسة قد تُحذف الملفات داخل `/content` والمكتبات التي ثبّتها الدفتر والمتغيرات مثل `BEST` و`IN_COLAB`. وعند إعادة تشغيل النواة وحدها تختفي المتغيرات والاستيرادات، وقد تبقى الملفات. لذلك خلية الواجهة القديمة وحدها لا تكفي في جلسة جديدة. ملف الدفتر المحفوظ في GitHub أو Drive لا يحفظ الجهاز أو أوزان التدريب تلقائيًا.

هذا الإصدار يضيف **دفتر تنبؤ مستقل بخلية واحدة**؛ لا يغيّر التدريب أو درجات النموذج أو تصميم الواجهة العامل، ولا يضمن استمرار جلسة Colab أو اتصالها. لم نعدّل أسماء الأوزان كي نمرر أوزان الأشكال باعتبارها كاشف وجوه.

## ثلاث خطوات للاستخدام

1. افتح [FaceJPEG_Daily_Predict.ipynb في Colab](https://colab.research.google.com/github/Aishaas1/Final-Projects/blob/main/FaceJPEG_Daily_Predict.ipynb) واضغط تشغيل الخلية الوحيدة. يكفي CPU. إذا طُلب تثبيت مكتبات انتظر انتهاءه.
2. ارفع **ملف النموذج أولًا**: `best.pt` الناتج من تدريبك على الوجوه، أو `selected_model_results.zip` الناتج من التحسين، أو ZIP نتائج المقارنة، أو `facejpeg_model_backup.zip`. هذه الخطوة لا تطلب صورة الوجه. ملفات JPG/PNG تُرفع داخل الواجهة بعد فتحها.
3. احتفظ بالنسخة الاحتياطية التي يطلب الدفتر تنزيلها إلى جهازك، ثم افتح رابط Gradio الجديد وارفع صورة واحدة واختر جودة JPEG واضغط التحليل. يمكنك تجربة صور أخرى في الواجهة نفسها دون إعادة تشغيل الخلية ما دامت الجلسة قائمة.

إذا انتهت الجلسة، كرر الخطوات وارفع النسخة الاحتياطية. لا تحتاج صور التدريب أو تنزيل Kaggle أو إعادة تدريب أو Google Drive من أجل التنبؤ. إذا أغلقت الصفحة وبقيت الجلسة والخادم يعملان فقد يبقى الرابط متاحًا، لكنه ليس استضافة دائمة.

**إذا لم تحتفظ بالنموذج خارج جلسة انتهت وحُذفت ملفاتها، لا يستطيع هذا الدفتر استعادته.** ابحث في التنزيلات وGoogle Drive عن `best.pt` أو ZIP نتائجك السابق؛ لا تستخدم ملفًا من `artifacts/smoke` أو `artifacts/review/quick` لأنه اختبار أشكال هندسية فقط.

## أي نموذج أرفع من مقارنة A وB؟

- A هو `baseline/best.pt` من التدريب الأساسي.
- B هو `jpeg_augmented/best.pt` من التدريب مع ضغط JPEG عشوائي لصور التدريب.
- إن شغّلت خلية تحسين الأوزان وأنتجت `selected_model_results.zip`، ارفع ذلك ZIP أو ملف `best.pt` المختار داخله.

للنتائج القديمة التي تضم النموذجين، `MODEL_CHOICE="jpeg_augmented"` هو اختيار B الافتراضي ويمكن تغييره إلى `baseline`. هذا اختيار المستخدم وليس حكمًا أن B أفضل دائمًا. إن احتوى ZIP نموذجًا مختارًا باسم `best.pt` في جذره، يُستخدم ذلك الملف. عند وجود عدة نماذج مبهمة يتوقف البرنامج ويطلب رفع `best.pt` المقصود بدل التخمين. الأفضل رفع الملف المطلوب وحده.

## ما الذي تحفظه النسخة الاحتياطية؟

يحفظ `facejpeg_model_backup.zip` ملف `best.pt` نفسه دون تغيير، وبصمة SHA256، وترتيب الفئات، وإعدادات المعالجة وحدود القرار، وتعليمات عربية قصيرة. يتحقق البرنامج من البصمة عند الاستعادة. لا يحتوي ZIP صور التدريب ولا يحوّل الدرجة إلى احتمال معاير. يحفظ التنبؤ على CPU لتقليل اعتماد التشغيل على GPU؛ يبقى الحكم وفق حدود النموذج المحفوظة نفسها، مع احتمال فروق حسابية ضئيلة بين المنصات.

يحاول الدفتر بدء تنزيل ZIP، لكن عليك التأكد من وصوله إلى جهازك. إذا منع المتصفح التنزيل التلقائي افتح لوحة Files في Colab، ثم المجلد `facejpeg_daily_...`، وانقر بجانب `facejpeg_model_backup.zip` واختر Download. احتفظ بنتائج التدريب الكاملة أيضًا إذا أردت لاحقًا استكمال التدريب أو مراجعة التقارير؛ ZIP النموذج وحده مخصص للتنبؤ.

## المشاكل التي عالجها هذا المسار

| ما يظهر | المعالجة |
|---|---|
| `No module named facejpeg` | يُكتب كود المشروع المضمن وتُضبط الاستيرادات داخل الخلية نفسها قبل فتح الواجهة. |
| `IN_COLAB` أو `BEST` غير معرف | تكتشف الخلية Colab وتستعيد النموذج دون الاعتماد على متغيرات جلسة قديمة. |
| فشل مصادقة Drive | لا نركّب Drive. يمكنك رفع النموذج من جهازك. |
| أوزان QUICK هندسية | تُرفض برسالة واضحة؛ لا تعرض نتائج كشف وجوه. |
| `best.pt` تالف أو ZIP بيانات بدل نتائج | تظهر رسالة عربية تحدد الملف المطلوب، دون تدريب بديل أو حذف نموذج موجود. |
| رابط Gradio قديم توقف | شغّل الخلية واستخدم الرابط الجديد؛ الرابط يحتاج خادمًا عاملًا. |
| تحذير Gradio عن `api_name=False` | نستخدم Gradio5.50.0 ونتجاهل تحذيرات الإهمال المستقبلية المعروفة فقط، دون إخفاء أخطاء التشغيل. |
| مكتبة مختلفة محمّلة مسبقًا | احفظ الأوزان ثم افتح جلسة جديدة وشغّل هذا الدفتر وحده؛ لا نستبدل مكتبة محمّلة داخل النواة. |
| `Too many sessions` أو انقطاع الاتصال | هذه مشاكل إدارة Colab: أنهِ الجلسات غير المستخدمة من Manage sessions ثم اتصل مجددًا. الكود لا يمدد حصة الحساب. |

لم نختبر حسابك أو اتصالك أو ملف أوزانك الذي لم يصل إلينا. لا ندّعي أن تحديث بدء التشغيل يرفع دقة كشف الوجوه. نتائج300 صورة التي أرسلتها محفوظة في [سجل النتائج السابقة](USER_REPORTED_RESULTS_AR.md)، وهي مستقلة عن اختبارات البرمجيات هنا.

## تشغيل محلي

من نسخة المشروع، استخدم بيئة Python مدعومة ونسخة متوافقة من Torch/Torchvision وفق [تعليمات PyTorch](https://pytorch.org/get-started/locally/)، ثم:

```bash
python -m pip install -r requirements-daily-colab.txt
FACEJPEG_CHECKPOINT=/path/to/best.pt python daily_predict.py
```

يفتح Gradio محليًا دون رابط مشاركة عام. `daily_predict.py` مكافئ للخلية الوحيدة، ويضم الكود نفسه. للمطور: تغيير `FACEJPEG_DAILY_HOME` يحدد مجلد العمل، و`FACEJPEG_NO_UI=1` يتحقق من التحميل والنسخ الاحتياطي دون بدء خادم. بوابة رفض الأوزان الهندسية تبقى مفعّلة في المدخل العام.
