# رابط ثابت باستضافة مجانية — Streamlit Community Cloud

هذه واجهة إضافية للنشر المجاني تستخدم نفس `facejpeg.infer.Predictor` ونموذج MobileNetV3 ومعالجة الصور وحدود القرار المحفوظة. واجهة Gradio ودفاتر التدريب والتنبؤ الموجودة في المشروع تظل متاحة. لا يحدث تدريب أو تنزيل بيانات أو أوزان ImageNet عند بدء خدمة النشر.

راجعنا [التوثيق الرسمي](https://github.com/streamlit/docs/blob/main/content/deploy/community-cloud/_index.md) في8 نوفمبر2026؛ يصف Community Cloud بأنها مجانية. تحتاج حسابًا وربطه بحساب GitHub الذي يملك هذا المستودع. لم ننشئ حساب استضافة أو تطبيقًا نيابة عنك، ولم نصدر رابط تشغيل فعليًا بعد.

## قبل النشر: حفظ نموذج الوجوه

بعد إتمام REAL_CPU أو REAL على بيانات وجوه فعلية، نزّل `best.pt` من المرحلة9 في دفتر التدريب أو استخرجه من ZIP النتائج. من صفحة هذا المجلد في GitHub اختر Add file → Upload files، وارفعه بالاسم `best.pt` ليصبح مساره:

```text
deploy/streamlit/best.pt
```

يكفي هذا الملف للتنبؤ؛ لا ترفع مجموعة التدريب أو prepared أو feature_cache أو last.pt. يحتوي best.pt على الشبكة كاملة وترتيب الفئات والمعالجة وحدود القرار. عند غيابه تظهر رسالة إعداد دون تصنيف؛ عند فساد الملف تظهر رسالة خطأ. أوزان QUICK تتيح معاينة JPEG فقط، مع إخفاء الأحكام والدرجات. لا توجد أوزان كشف وجوه مدربة مضمنة في المستودع حاليًا. تغيير اسم ملف QUICK لا يغير هذه الحقيقة.

رفع best.pt إلى المستودع العام يجعله قابلًا للتنزيل مثل بقية الملفات. لا تُرفَع الصور التي يفحصها الزائر إلى GitHub ولا تُستخدم في التدريب.

## نشر التطبيق

1. افتح [share.streamlit.io](https://share.streamlit.io/) وسجّل الدخول واربط GitHub من واجهة الخدمة.
2. اضغط Create app أو New app، واختر النشر من مستودع GitHub. استخدم هذه القيم:

   | الحقل | القيمة |
   |---|---|
   | Repository | `Aishaas1/Final-Projects` |
   | Branch | `main` |
   | Main file path | `deploy/streamlit/app.py` |
   | Advanced settings → Python version | `3.12` |

3. اختر اسم الرابط إن عرضت الخدمة ذلك، ثم اضغط Deploy. تنتظر الخدمة تثبيت المتطلبات وتشغيل التطبيق؛ لا حاجة لمفتاح Kaggle أو GPU أو أسرار أو Colab.
4. عند اكتمال التشغيل انسخ عنوان `.streamlit.app` الذي تعطيه المنصة. هذا هو رابط الفحص الذي ترسله للمدرب. لا نخمن اسم نطاق لم تنشئه المنصة بعد.

تعثر البناء: افتح Manage app ثم السجلات، وتأكد من المسار وPython3.12. تبحث الخدمة عن requirements.txt في مجلد ملف التشغيل قبل جذر المستودع، ولذلك تستخدم هذه النسخة الخفيفة بعجلات CPU. عند تحديث التطبيق أو best.pt في GitHub تعيد الخدمة تشغيل التطبيق من ملفات المستودع.

## استخدام الرابط لاحقًا

افتح رابط التطبيق مباشرة، وارفع JPG/PNG لوجه واحد، واختر جودة JPEG ثم اضغط التحليل. لصور أخرى بدّل الملف واضغط الزر. لا تُشغّل Colab ولا تعيد التدريب لكل زيارة.

الرابط ثابت ما دمت تحتفظ بالتطبيق والاسم والحساب؛ الاستضافة المجانية قد تُدخل التطبيق في وضع النوم عند الخمول، فتظهر صفحة لإيقاظه عند الزيارة. قد يستغرق الإقلاع أو تحميل النموذج قليلًا. لا نعد بتشغيل متواصل24/7 أو بحدود موارد ثابتة. راجع [حدود الخدمة وإدارتها](https://github.com/streamlit/docs/blob/main/content/deploy/community-cloud/manage-your-app/_index.md).

## التشغيل المحلي

من جذر المشروع، بعد تثبيت المتطلبات المناسبة لـPython3.12:

```bash
python -m pip install -r deploy/streamlit/requirements.txt
python -m streamlit run deploy/streamlit/app.py
```

يحمّل التطبيق افتراضيًا best.pt من مجلده. المتغير البيئي الاختياري FACEJPEG_CHECKPOINT يحدد مسارًا آخر للاختبارات المحلية؛ لا حاجة له في النشر المعتاد.

## حدود النتائج

النشر لا يرفع دقة النموذج ولا يعوّض تدريب الوجوه أو التقييم المستقل. لا تُفسَّر درجات الأشكال الهندسية كدقة كشف. صور العرض موحدة224×224، وكل نسخة JPEG تُنشأ مباشرة من الأصل الموحد بالمعالجة نفسها للفئتين. كاشف الوجه البسيط قد يرفض وجوهًا جانبية أو صغيرة. لا تتجاوز15MiB أو25 مليون بكسل.

اجتازت الاختبارات المحلية39 اختبارًا، منها7 للواجهة الإضافية: غياب النموذج وفساده، وصورتا وجه دون أحكام أصالة باستخدام أوزان QUICK، وصورة تالفة وبلا وجه وبوجوه متعددة. اختُبر رفع صورة فعلًا في Chromium محليًا، وعُرضت الصورتان PNG؛ طابقت بكسلاتهما الأصل الموحد وJPEG70 من كود المعالجة المشترك تمامًا.
